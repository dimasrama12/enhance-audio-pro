How should conversion progress appear?

Each option requires a different level of FFmpeg integration. Pick the one that fits your expectations.

vocals.wav → mp3
Converting…
drums.wav → mp3
Done

A — Simple Progress Bar

Animated indeterminate bar during conversion, turns solid green on done. Same as the existing enhance flow. No FFmpeg stdout parsing needed.

vocals.wav → mp3 63%
drums.wav → mp3 100%
2.4 MB

B — Accurate % + Per-job Cancel

Real time-based percentage from FFmpeg's -progress output. Cancel button per row. Output file size shown when done. Requires FFmpeg stdout streaming.

vocals.wav → mp3 63% · 1.2× · ETA 8s
Speed: 1.2× Bitrate: 128kb/s Size so far: 1.5 MB ETA: 8s
Pause Cancel

C — Rich Stats Panel

Live speed multiplier, ETA, current bitrate, running file size. Pause + Cancel controls. Maximum visibility — highest implementation effort.
