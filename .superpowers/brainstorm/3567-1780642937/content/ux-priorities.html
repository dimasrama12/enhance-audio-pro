Codec-Specific Settings

Progress & Cancellation

Real-time accurate FFmpeg progress (time-based %, not chunk-based), per-job cancel button, retry on error, timeout recovery. The current callback flow exists but FFmpeg progress granularity and individual job cancellation need hardening.

Output Preview & File Management

Show estimated output file size before conversion, output filename preview with template tokens, per-job destination folder override, open-in-explorer button after done, duplicate output detection.

D

Batch Workflow & Presets

Named conversion presets (e.g. "Podcast MP3 128k", "Archival FLAC 48k"), apply preset to all selected jobs, convert selected only vs. convert all, queue reordering effect on conversion order.
